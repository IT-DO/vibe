# Подготовка планшета

Цель — планшет, с которого гость не может выйти в систему, экран которого не
гаснет весь вечер, и который после случайной перезагрузки сам возвращается в
приложение.

## Android

### Вариант 1: закрепление экрана (5 минут, без компьютера)

Годится для репетиции и для мероприятий, где будка стоит на виду у
организатора.

1. **Настройки → Безопасность → Закрепление приложения** — включить.
2. Открыть «Фото на память». Приложение само вызовет закрепление;
   подтвердить запрос системы.
3. **Настройки → Экран → Спящий режим** — «Никогда» (приложение и так держит
   экран, но так надёжнее).
4. **Настройки → Приложения → Приложения по умолчанию → Главный экран** —
   выбрать «Фото на память». После перезагрузки планшет вернётся в будку, а
   не в лаунчер.

Ограничение: выйти можно долгим одновременным нажатием «Назад» и «Обзор».
Гость случайно так не сделает, но специально — сможет.

### Вариант 2: владелец устройства (настоящий киоск)

Приложение назначается владельцем устройства, и тогда закрепление включается
молча, а выйти из приложения нельзя вообще.

**Требование:** на планшете не должно быть ни одного добавленного аккаунта.
На практике это значит — сбросить его к заводским настройкам и **не входить
в Google-аккаунт** при первичной настройке.

```bash
# 1. Сброс к заводским настройкам, первичная настройка БЕЗ аккаунта Google.
# 2. Включить отладку по USB (Настройки → О планшете → 7 раз по «Номер сборки»,
#    затем Настройки → Для разработчиков → Отладка по USB).
# 3. Установить приложение:
adb install app-release.apk

# 4. Назначить владельцем устройства:
adb shell dpm set-device-owner com.photonapamyat/.KioskDeviceAdminReceiver
```

Ответ `Success: Device owner set` означает, что всё получилось. Ошибка
`Not allowed to set the device owner because there are already several users`
означает, что на планшете остался аккаунт — нужен сброс.

Дальше — пункты 3 и 4 из первого варианта.

**Как снять:** админка → «Выйти из киоск-режима», затем
`adb shell dpm remove-active-admin com.photonapamyat/.KioskDeviceAdminReceiver`.

### Разрешения

При первом запуске приложение попросит доступ к камере — выдать.

Больше приложение ничего не просит. Разрешения на геолокацию в нём нет
намеренно: с Android 10 оно требуется, только чтобы показать имя Wi-Fi сети
в админке, а фотобудка, которая просит доступ к местоположению, вызывает
вопросы на ровном месте. Поле «Сеть» в админке поэтому остаётся пустым;
поиск принтера от этого не страдает.

## iOS

Программно закрепить приложение на iOS нельзя: Apple не даёт такого API
обычным программам. Штатный способ — **Гид-доступ**.

1. **Настройки → Универсальный доступ → Гид-доступ** — включить.
2. Там же **Настройки код-пароля → Задать код-пароль Гид-доступа** —
   задать код (и не тот же, что у админки приложения).
3. Открыть «Фото на память», **трижды нажать боковую кнопку** (или кнопку
   «Домой» на старых iPad).
4. В открывшемся окне — «Параметры»: выключить «Нажатие» в тех зонах экрана,
   которых гость касаться не должен (не обязательно), включить «Блокировка
   автоблокировки». Нажать «Начать».
5. Выход — тройное нажатие боковой кнопки и код-пароля.

Приложение видит, включён ли Гид-доступ, и показывает состояние в админке.

### Локальная сеть — обязательный пункт

Начиная с iOS 14 система **молча блокирует** обращения к устройствам
локальной сети, пока пользователь не дал разрешение. Приложение при этом не
получает ошибку — принтер просто «не находится».

При первом поиске принтера iOS покажет запрос «Разрешить доступ к устройствам
в локальной сети» — **обязательно разрешить**. Проверить и включить потом:
**Настройки → Фото на память → Локальная сеть**.

За это отвечают ключи `NSLocalNetworkUsageDescription` и `NSBonjourServices`
в `ios/PhotoNaPamyat/Info.plist`; без них разрешение вообще не запрашивается.

## Физическая установка

| Что | Как | Почему |
|---|---|---|
| Высота планшета | Центр экрана на 140–150 см | Средний рост глаз стоящего человека. Ниже — все снимки снизу вверх |
| Наклон | 5–10° назад | Компенсирует разницу в росте гостей |
| Ориентация | Портрет | Лист 10×15 портретный; групповой кадр всё равно кадрируется |
| Расстояние до гостей | 1,2–1,8 м | Ближе — влезает один человек, дальше — не читается экран |
| Принтер | Рядом, лоток выдачи наружу | Гость должен видеть, откуда забирать |
| Питание | Оба от сети, не от батареи | Планшет с постоянно включённым экраном и камерой садится за 3–4 часа |
| Свет | Мягкий источник за планшетом, направленный на гостей | Иначе лица в контровом свете |

Кабели стоит закрепить: за вечер о них споткнутся.

## Проверка перед мероприятием

1. Открыть админку (удержать левый верхний угол 5 секунд, ПИН 2468).
2. «Найти принтер» → выбрать → состояние «Готов».
3. Задать название мероприятия и подпись.
4. Оставить нужные форматы.
5. Сбросить счётчики.
6. Пройти сценарий целиком: сфотографироваться, напечатать, забрать лист.
7. Проверить лист: нет белой полоски по краю, головы не обрезаны, подпись
   на месте, надписи не зеркальны (если это важно).
8. Выйти из админки, включить киоск-режим.
